# SRP School – React + Tailwind

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Stack: React 18, Vite, Tailwind CSS 3, react-icons.
All copy, links and image URLs live in `src/data.js`. Photos are Unsplash URLs; a gradient fallback shows if one fails to load, so you can swap in your own images freely.
